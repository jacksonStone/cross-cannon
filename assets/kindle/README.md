# Kindle cover artwork

`christ-pantocrator-sinai.jpg` is a reproduction of the sixth-century
*Christ Pantocrator* icon held at Saint Catherine's Monastery, Sinai.
Wikimedia Commons identifies both the artwork and this faithful reproduction
as public domain:

https://commons.wikimedia.org/wiki/File:Christ_Icon_Sinai_6th_century.jpg

`cross-canon-bible-cover.svg` applies the title treatment.
`cross-canon-bible-cover.jpg` is the 1600 × 2560 rendered cover embedded in the
Kindle EPUB.

`first-clement-cover.svg` applies the title treatment for First Clement.
`first-clement-cover.jpg` is the rendered cover embedded in that Kindle EPUB.
Its source artwork is Giovanni Battista Tiepolo's 1737–1738 painting
*Pope St Clement Adoring the Trinity*. `first-clement-tiepolo.jpg` is the
public-domain Yorck Project reproduction from Wikimedia Commons:

https://commons.wikimedia.org/wiki/File:Giovanni_Battista_Tiepolo_016.jpg
