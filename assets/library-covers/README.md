# Library cover art

- **Confessions** (`npnf101:vi`). Benozzo Gozzoli, *St Augustine Reading the Epistle of St Paul*, 1464–65. The fresco illustrates the conversion recounted in *Confessions* VIII.12. The image here is a resized reproduction. [Augustinian Historical Institute](https://www.augustiniana.be/public/?page_id=1692), [image and Public Domain Mark](https://commons.wikimedia.org/wiki/File:TolleLege.jpg)
- **The Imitation of Christ** (`classics:imitation`). Frontispiece etched by Charles Waltner from the 1886 J. C. Nimmo edition translated by William Benham. The image here is a resized scan from the University of California Libraries copy. [Archive record](https://archive.org/details/imitationofchris00benhrich), [frontispiece](https://archive.org/download/imitationofchris00benhrich/page/n9.jpg), [public-domain scan record](https://commons.wikimedia.org/wiki/File:The_imitation_of_Christ_-_four_books_(IA_imitationofchris00benhrich).pdf)
- The existing Bible and First Clement assets are documented in the [Kindle artwork credits](../kindle/README.md).

`bible-sinai-hero.jpg` is a resized copy of the Sinai icon. The files in `thumbnails/` are resized copies of the sources in the [cover inventory](../../docs/research/library-cover-inventory.json). The browser build gives each thumbnail a content-addressed URL so it is available in the offline library.
