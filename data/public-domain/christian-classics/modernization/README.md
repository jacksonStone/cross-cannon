# Reviewed modernized English overlays

The Imitation of Christ: all 114 chapters / 2,357 numbered source segments.
Modernized and reviewed with GPT-6.1 Terra, following the approved first-chapter
sample. Changes update archaic English and awkward word order while retaining
the historical translation's meaning, theological terms, imagery and citations.

Each JSON overlay contains the exact original text and its optional modernized
counterpart. Chapter batches, reviews, change audits and an independent sample
review are saved in `.scratch/christian-classics-modernization/`.

Use the existing assembler to validate a complete chapter and create an overlay;
use `npm run publish:christian-classics-modernization` to apply saved overlays to
new content-addressed assets. Original text and IDs remain intact. The explicit
Classics importer reapplies overlays, so rebuilding artifacts preserves this work.
No embeddings or databases are regenerated by modernization.
