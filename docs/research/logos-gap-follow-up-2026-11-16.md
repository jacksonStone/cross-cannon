# Logos gap analysis follow-up

Research date: November 16, 2026. This supplements the [November 12 comparison](cross-canon-logos-gap-analysis.md) and [Logos feature research](logos-daily-use-features.md). Logos claims below were checked against current official documentation; they describe capabilities, not hands-on quality or universal platform/license availability. Recommendations are product judgments.

## Correct the baseline first

The old comparison is historical, and several prominent gaps have changed:

- CrossCanon now has passage highlights and multiple Markdown notes across all three collections, local durability, offline editing, and revisioned account synchronization. Legacy bookmark/notebook metadata remains compatible; that alone does not establish a current organization interface. [Personal study](../personal-study.md)
- A second reading translation, MSB, exists alongside WEB. WEB remains passage/search identity; MSB covers its 66-book corpus and WEB supplies uncovered text. Translation breadth and comparison remain separate questions. [Reading translations](../content-maintenance.md#reading-translations)
- Local keyword search exists. Its current implementation requires all whitespace-separated query tokens as substrings of text or reference, then ranks matches. This is different from ordered phrase matching, whole-word search, or an exhaustive concordance. [Search implementation](../../rust/core/src/lib.rs)
- The staged browser reader supports offline study across the text library, and native apps bundle all text. Do not repeat the old limited-cache baseline. [Personal study](../personal-study.md), [architecture](../architecture.md)

## Additional opportunities beyond the original headline gaps

| User job | Logos documented capability | CrossCanon opportunity / inference |
| --- | --- | --- |
| “Where do the Fathers actually discuss this verse?” | Cited By follows a Bible or another primary source and finds references to its current location, scoped to books, collections or series. It requires structured primary-source references and explicitly does not find ordinary secondary-source citations. [Cited By](https://support.logos.com/hc/en-us/articles/360015718091-Using-the-Cited-By-Tool) | A reverse Scripture citation index across existing Fathers/Classics could give stronger evidence than similarity alone. First distinguish an explicit printed reference, an editor's cross-reference, and an inferred allusion. This is a proposed extension, not an assertion that every existing reference is currently unlinked. |
| “Is this a quotation, an allusion, or just a similar idea?” | Search templates distinguish OT citations, quotations, allusions and echoes in the NT. Passage Guide separately offers cross-references and parallel passages. [Search Templates](https://support.logos.com/hc/en-us/articles/360030747891-How-do-I-use-Search-Templates-to-Build-a-Search), [Passage Guide](https://support.logos.com/hc/en-us/articles/360016462872-Study-a-Passage-Using-the-Passage-Guide) | Treat these as different relationships with visible provenance. Semantic relatedness should not acquire an “allusion” label automatically. A small reviewed citation graph is a plausible CrossCanon fit; comprehensive scholarly classification is a larger task. |
| “Keep these six passages and three patristic quotations together.” | Passage Lists collect references from searches or selected book text, support headings/reordering and can become search scopes. Clippings retain excerpts, source links, bibliographic information, notes and tags; desktop supports export. [Passage Lists](https://support.logos.com/hc/en-us/articles/360016747311-How-to-Create-and-Use-a-Passage-List), [Clippings](https://support.logos.com/hc/en-us/articles/360016525152-Create-Organize-and-Export-Clippings) | Synced annotations solve personal retention. A named, ordered mixed-source study collection solves a different job: assembling material for later reading or discussion. Build on existing notes and stable anchors rather than assuming notes are still absent. |
| “Where else does Augustine say this in this book?” | Inline search searches the open resource, navigates matches and controls surrounding context; desktop can constrain fields/ranges. Mobile can search selected wording within the current book. [Inline Search](https://support.logos.com/hc/en-us/articles/360016524471-Search-within-an-Open-Book-Using-Inline-Search) | Scope and interaction matter as much as adding search syntax. Expose “this Work” directly from reading and preserve the return location. Prioritize dependable phrase/word behavior rather than describing CrossCanon as lacking keyword search. |
| “Let the commentary follow my reading.” | Logos link sets keep resources at a common reference, saved layouts retain the setup, and prioritization controls preferred resources. [Commentaries](https://support.logos.com/hc/en-us/articles/360038669172-How-do-I-use-commentaries-in-Logos) | CrossCanon's commentary dialog snapshots the selected passage and starts with its first available Work on each opening. Remembering a preferred commentator and offering a compact following view would deepen an existing feature. [Current commentary](../../rust/desktop/src/commentary.rs) |
| “What does this reference or footnote mean without losing my place?” | Power Lookup displays the text behind links in the active resource, including Bible references and footnotes, and can follow a panel. [Power Lookup](https://support.logos.com/hc/en-us/articles/360015718111-Find-Associated-References-with-the-Power-Lookup-Tool) | Preview cited Scripture while reading historical texts, with one-step opening and return. This can improve an existing catalog without purchasing many more books. Reference recognition and edition/editorial attribution need auditing first. |
| “Make this large library feel like mine.” | Logos Library filters include user collections and reading status; users can inspect tags, download status and bibliographic information and prioritize books. [Library](https://support.logos.com/hc/en-us/articles/360016752591-Find-Your-Books-in-the-Library) | Beyond Work favorites: user shelves, reading queue, per-Work resume and preferred resources are possible incremental improvements. Audit each against current catalog/navigation before classifying it as missing. |
| “Turn this study into something I can use elsewhere.” | Copy Bible Verses supports formatting and nonconsecutive references. Desktop Print/Export supports selected sections, filtered text and several file formats; mobile/web have simpler copy/paste. [Copy Bible Verses](https://support.logos.com/hc/en-us/articles/360015518272-Copy-Bible-Verses-from-Logos), [Print/Export](https://support.logos.com/hc/en-us/articles/360016476711-How-Can-I-Print-Export-Content-from-Logos) | A clean Markdown/plain-text export of a study collection, including excerpts, references, edition attribution and return links, is a smaller target than sermon software. Existing repository EPUB tooling does not by itself satisfy this in-app study workflow. |

## Product judgment

The strongest additional direction is an evidence-preserving loop: discover a related source, verify why it is connected, retain it with other sources, then retrieve or export the study. A citation index and mixed-source study collections use CrossCanon's existing historical library particularly well. Exact retrieval and reference previews improve that loop; remembering a commentator is a smaller standalone improvement. None requires generated explanations or replicating the entire Logos workspace.

This note does not establish current production feature parity, comparative search accuracy, implementation cost, or content rights. Current CrossCanon details above are source/documentation findings, not a fresh browser acceptance test.
